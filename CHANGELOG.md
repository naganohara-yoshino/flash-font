# Changelog

## v0.3.2 - 2026-04-30

- Added optional desktop notifications after ASS subtitle fonts are loaded.
- Added configuration support for notification preferences during `flash-font-ass init`.
- Added system font availability checks so fonts already installed on the system are not reported as missing.
- Updated `flash-font-injector` to `0.6.1`.
- Fixed missing-font reporting for fonts available from the system font table.
- Fixed minor CLI and library issues, including clippy cleanups and dependency updates.

## v0.1.1

- Initial release.
